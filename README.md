# 飛行棋（多人連線）

經典中國**飛行棋**（Fei Xing Qi / Aeroplane Chess），不是簡化版 Ludo。瀏覽器即時對戰，伺服器為權威狀態；空位由電腦補滿四家。

棋盤外觀依 Wikimedia Commons 經典十字盤 [Fei xing qi board (BYGR).svg](https://commons.wikimedia.org/wiki/File:Fei_xing_qi_board_(BYGR).svg)（Mliu92，CC BY-SA 4.0）實作。

## 本機執行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

瀏覽器開啟 <http://127.0.0.1:43177>。正式啟動用 `npm start`。環境變數 `PORT` 可改埠號。

跑規則測試：

```bash
npm test
```

兩開分頁即可同房對戰：一頁「建立房間」，另一頁輸入四碼房間代碼或開啟複製的連結，雙方準備後開局（缺人由電腦補）。

## 部署（公開 HTTPS）

伺服器綁定 `0.0.0.0` 與 `process.env.PORT`（平台會注入）。房間狀態在記憶體裡，**請保持單一實例**，不要水平擴充。

- Render：Blueprint 檔是 `render.yaml`（免費 Web Service、`npm install` / `npm start`、健康檢查 `/healthz`、`numInstances: 1`）。把 **GitHub 公開鏡像**接到 Render；閒置後會休眠，第一次開啟可能要等約一分鐘。
- Fly.io：`fly launch` / `fly deploy`（`fly.toml` + `Dockerfile`）。
- Railway：`npm start`，讀 `Procfile`。

## 怎麼玩

1. 輸入暱稱，建立或加入房間。
2. 點「準備」。房內所有玩家都準備後自動開局；未入座的黃／綠／紅／藍由電腦執飛，永遠四家。
3. 輪到你時「擲骰」。若有多架可走的飛機，點選棋盤上發亮的那架。
4. 先把四架飛機全部送進終點的人獲勝。

重新整理可憑同一個瀏覽器分頁還原（房間代碼 + 玩家 id 存在 sessionStorage）。

## 已實作規則

傳統玩法（維基百科「飛行棋」傳統規則 + Yellow Mountain Imports 說明）：

- 每方四架飛機，從角落機場出發。必須擲出 **6** 才能起飛到起飛格；已有飛機在外時，6 點可起飛或走現有飛機。尚未有任何飛機離場時（四架都在機場），該玩家擲出 6 的機率為 **1/4**（比公平骰高五成），1–5 點均分其餘機率；只要有一架成功起飛，之後改回公平六面骰。電腦座位同一規則。
- 擲出 6 走完後再擲一次。同一回合連續三次 6：**三次六返大陸**，將本回合剛走過的飛機（若已不在場則改選仍在跑道／終點跑道者）遣返機場，不走第三步。
- 順時針沿 52 格外圈前進。走到自己顏色的格子（終點跑道除外）再跳 4 格。
- 若**擲骰後**正好停在己色長虛線起點：沿虛線飛到對面，再跳 4 格。若是**跳到**虛線起點：仍可飛過，但不再加跳 4 格。飛航途中會吃掉對家終點跑道與虛線交會格上的敵機，以及落點上的敵機。
- 停在敵機上：該格全部敵機返回機場（**迭子整疊被吃**）。己方飛機可疊在同一格，但分開移動，不一起走。
- 走到己色拐彎箭頭後轉入中央大箭頭（每方外圈有兩格到不了，因為在此轉彎）。步數超過終點則在終點**反彈**。剛好走到終點即完成，面朝下置回機場並標示「完」。
- 電腦策略：吃子 > 有用的起飛 > 盡量走最前面的棋 > 能完成則完成；只走合法步，並稍作停頓方便動畫。
