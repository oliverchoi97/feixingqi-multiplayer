# Gaming In My Life

瀏覽器小遊戲入口（繁體中文）。公開網址 [gaminginmylife.onrender.com](https://gaminginmylife.onrender.com)。

## 本機執行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

瀏覽器開啟 <http://127.0.0.1:43177>。正式啟動用 `npm start`。環境變數 `PORT` 可改埠號。

| 路徑 | 內容 |

| `/` | 選遊戲 |
| `/feixingqi` | 飛行棋（`/?room=代碼` 會轉到這裡） |
| `/minesweeper` | 踩地雷：單人 A/B/C，或雙人高級競賽 |

| `/oldmaid` | 抽烏龜 |

跑測試：`npm test`。兩開分頁即可同房。

候機室與對局底部可開彈幕聊天；對局中另有 **記錄** 可捲看本局訊息（暱稱、內容、時間）。彈幕照常飛過。結束遊戲、回到主選單、或重開一局會清空。中途重連同一局會從伺服器補上本局紀錄（不跨局、不寫進瀏覽器）。手機上聊天欄固定在視窗底部，不必把頁面捲到底。

全站左下角有 **開啟音樂／靜音**（`public/js/bgm.js`），用 YouTube IFrame API 循環播放公開播放清單 [PLxj77DstROao_Y-Ypu-P0jAiNMwK2hHAr](https://www.youtube.com/playlist?list=PLxj77DstROao_Y-Ypu-P0jAiNMwK2hHAr)。不需登入。瀏覽器常會擋住有聲自動播放：第一次點「開啟音樂」（或之後任一操作）才出聲；選擇會記在 localStorage，換頁仍有效。播放清單須維持**公開或未列出**才能嵌入；若改成私人，按鈕會顯示無法播放。

候機室與對局聊天可輸入 **`/song 歌手+歌`** 或 **`/song artist song`**（`/song` 後面空白可有可無，之後整段當搜尋字）。伺服器用 YouTube Data API v3 `search.list` 取第一筆可嵌入影片，用 Socket.IO 廣播 `song`（含 `videoId`）給同房所有人，共用同一個 IFrame 播放器插播；該曲結束後從**插播前那一首**繼續循環播放清單（記住 playlist index／videoId，不從清單第一首重來）。YouTube IFrame 在 `loadVideoById` 之後往往接不上秒數，所以該首通常從開頭播。彈幕不會出現原始 `/song …` 指令，改為「🎵 正在播放：…」。每位玩家與每個房間約 20 秒只能插一次；查詢會去掉 HTML，最長 56 字。首頁沒有聊天欄，此指令只在各遊戲頁有效。踩地雷單人沒有房間，改走 `GET /api/song?q=`，只在自己這台播放。

需要環境變數 **`YOUTUBE_API_KEY`**（或 `GOOGLE_API_KEY`），不要把金鑰寫進程式。未設定時聊天會提示「插歌未設定 API key」。本機可在啟動前 `export YOUTUBE_API_KEY=你的金鑰`。Google Cloud 專案須啟用 **YouTube Data API v3**。

每個遊戲在**對局進行中**有 **結束遊戲**，候機室與對局都有 **回到主選單**（需確認）：

- **結束遊戲**：只在開局後顯示。伺服器強制結束該房目前對局。飛行棋／棋類／猜猜畫畫／派對遊戲回到該遊戲候機室；踩地雷回到模式選擇。房間裡其他人一齊離開對局畫面。單人踩地雷要等**揭開第一格**才出現（選難度後的空盤不算開局）。
- **回到主選單**：同樣強制結束，按的人回到 `/` 選遊戲；其他人回到該遊戲開局前畫面。

候機室與對局中都可使用。有人加入房間時，房主畫面會立刻更新，不必重新整理。

## 部署（公開 HTTPS）

伺服器綁定 `0.0.0.0` 與 `process.env.PORT`。房間狀態在記憶體裡，**請保持單一實例**。

- Render：讀 `render.yaml`（免費 Web Service、`npm install` / `npm start`、健康檢查 `/healthz`、`numInstances: 1`）。閒置後會休眠。插歌請在 Dashboard → Environment 新增密鑰 `YOUTUBE_API_KEY`（`render.yaml` 以 `sync: false` 宣告，不會把金鑰寫進 repo）。
- Fly.io：`fly.toml` + `Dockerfile`。
- Railway：讀 `Procfile`。

## 飛行棋

經典中國飛行棋（不是 Ludo）。棋盤外觀依 Wikimedia Commons [Fei xing qi board (BYGR).svg](https://commons.wikimedia.org/wiki/File:Fei_xing_qi_board_(BYGR).svg)（Mliu92，CC BY-SA 4.0）。

1. 輸入暱稱，建立或加入房間。
2. 在候機室**選擇角色**（黃貓、藍狗、綠龜、紅兔），再點「準備」。開局前可更換；未選的角色由電腦補滿四家。
3. 輪到你時在棋盤中央向上滑動骰子（也可點一下）。
4. 四方棋子全部進終點者獲勝。棋子圖示：黃貓、綠龜、紅兔、藍狗。

重新整理可憑同一個分頁還原（房間代碼 + 玩家 id 在 sessionStorage）。

傳統規則：**擲 2、4 或 6 起飛**、同色跳四、虛線飛航、終點反彈、三次六返大陸。起飛只落到起飛格，不額外走步、也不吃該格上的棋。尚未有任何飛機離場時（四架都在機場），該玩家擲出 2／4／6 的合計機率約 **66%**；只要有一架成功起飛，之後改回公平六面骰。**再擲一次仍只有擲出 6。** 電腦同一規則。

對局中可開 **託管**：由電腦代打你的座位；再按 **取消託管** 收回操作。中途斷線也會改由電腦代打，重連後可繼續。

任何人擲骰（含電腦）時，房間裡每位玩家都會看到中央骰子翻滾與點數。回合提示在棋盤上方，不會擋住棋盤。

## 踩地雷

- **單人** 選經典難度：A 初級 9×9／10 雷、B 中級 16×16／40 雷、C 高級 30×16／99 雷。第一格保證安全。盤面上有 **踩／插旗** 模式切換（預設踩）：點格子依目前模式揭開或插旗。右鍵或長按仍可插旗。踩雷後可按「時光倒流」撤回上一手（僅一步），繼續同一盤。**結束遊戲**在揭開第一格後才出現（插旗不算開局）。
- **雙人競賽** 固定高級 C，最多 2 人、無電腦。開局用同一種子佈雷，雙方棋盤完全相同。**第一格不保證安全。** 同樣用踩／插旗按鈕操作。先揭完所有安全格者勝；踩雷即出局，對手若仍在場即獲勝。幾乎同時的操作以伺服器先處理的為準。對局中斷線視為棄權。**競賽不可時光倒流。**
- 對局畫面底部可聊天。多人房間會廣播彈幕；單人模式只在本機顯示。

## 棋類

雙人為主，候機室一人準備後也可開局（空位由電腦執白／後手）。

- **黑白棋**：標準 8×8、翻子；無子可下則虛手，終局比子數。
- **五子棋**：10×10 無禁手，連五即勝。
- **圍棋（9×9 MVP）**：提子、禁止自殺、簡單劫（不可立即回提）。連續兩次虛手終局，以簡單領地＋子數估算（白貼 6.5 目），不處理複雜死活。
- **過三關**：3×3，三連即勝。盤上最多同時 7 子：落下第 8 子時先看有沒有三連，沒有則最早落下的子消失再判一次。格子角落數字是落下順序。

## 猜猜畫畫

2–6 人，沒有電腦。房主在兩人進房後即可開局（不必全員按準備）。畫家每輪從三個詞裡選一題，也可 **換一題**；猜中後進入「答對」揭示再換人。內建約一千個繁體詞，房間可 **自行新增詞語**（寫進本房詞庫，最多記住 80 個自訂詞）。畫家看到題目並在共用畫布作畫（筆畫經 Socket 同步）；其他人在猜題欄輸入，猜中者 +2、畫家 +1。每題約 80 秒。彈幕聊天與猜題分開。

## 估數字 / 1A2B

2–4 人。兩人以上時由房主出四位不重複數字（也可按隨機），其餘人輪流猜。A 是位置與數字都對，B 是數字對但位置不對。先 4A 者勝。一人也可開，空位由電腦補上，此時由系統出題、人機輪流猜。

## 海戰棋

兩人 10×10。艦艇長度 5／4／3／3／2。**佈署 60 秒**（可隨機鎖定；逾時由系統代為佈署），**射擊每回合 30 秒**（逾時隨機開火）。一人也可對電腦。

## 冚棉胎

2–6 人輪流出牌。出現連續相同點數時搶按「冚」；時間窗約 1.6 秒。最慢按下的人收下那一墩，誤冚也要收走牌堆。先出完手牌者勝。**空位不會由電腦補上**，必須真人進房。

## 抽烏龜

預設 4 人（空位由電腦補上）。抽出黑桃 Q 當烏龜，開局自動丟掉對子。輪到你時從左邊抽一張，對子再丟掉。最後手上還有牌的人輸。

```
public/          入口與各遊戲介面（含共用 BGM 模組）
```
